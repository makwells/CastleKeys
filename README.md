<h1 align="center">Password-Manager</h1>

Менеджер паролей с возможностью сохранять их в облаке. 
Проект сделан для себя и в ближайшее время публиковаться не планируется. 

### Особенности: 
 * Сохранение паролей в облаке. 
 * Возможность использовать на любом устройстве. 
 * Система аккаунтов, в которых сохраняются пароли.
 * Интеграция в браузер. 
 * Удобный поиск паролей. 
 * Возможность генерации паролей. 
 * Возможность кастомизации меню. 

Так же можно сохранять ключи доступа (API ключи, токены итд).
